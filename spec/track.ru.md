# Трек: сетевые профили

Статус: **ЧЕРНОВИК**, 2026-09-23. Спецификация: `spec/network-profiles.ru.md` (черновик, N1–N14, учтены два независимых ревью). Роадмап: веха M7, после архивации agents-infra (решение оператора 2026-09-23: сеть идёт после launch profiles).

## Зачем

Нескольким агентам на одной машине нужно выходить в сеть через разные выходы уровня приложения (VPN A, VPN B, корпоративный прокси). При этом нельзя менять ни оркестратор, ни соседних агентов, ни операционную систему.

## Что строим

- Библиотеку `curator-network-profiles` (собственный публичный репозиторий; ей пользуются task-board и публичный `curator-run`): resolve → validate → probe → patch.
- `--network-profile <name>` у `curator run`, `task-board spawn`, `task-board claude|codex`; значения по умолчанию из слоя оператора (выбор агентов) и привязок сред выполнения.
- Патч применяет хост, который создаёт процесс (`unset`, затем `set`), и никогда через общее окружение; привязки сравниваются по дайджесту; возобновление при изменившемся профиле отклоняется.

## Вехи

| Шаг | Что даёт | Готово, когда |
| --- | --- | --- |
| N-A | библиотека, файл профилей `$XDG_CONFIG_HOME/curator-network-profiles/network.json`, `netrun --profile X -- <cmd>`, приложение с контрактом (дайджест, `EnvPatch`, равенство) | два ручных запуска используют два выхода в сеть |
| N-B | `curator run --network-profile` | лаунчер применяет патч через модуль |
| N-C1 | явный профиль на каждом пути процессов task-board и tb-sessiond, манифесты запусков | дочерний агент и сессия доски используют профиль, включая повтор и возобновление |
| N-C2 | значения по умолчанию из слоя оператора, привязок сред выполнения и проекта | запуски получают свой выход в сеть без флага |
| N-D | управляемый шлюз (sing-box), затем эпик принудительной песочницы | автоматическое развёртывание прокси |

## Зависимости

N-C1 нужны M2 и M3 (task-board и tb-sessiond собирают запуски через модуль); N-C2 нужна M4 (слой оператора и привязки). Мост инструментов Apiary должен держать собственный транспорт вне профиля агентской среды (NP-N11).
